# bnuyper

A buny typing test written in x86-64 assembly using FASM.

## Build

```bash
make
```

## Usage

Run without arguments to use the builtin typing test:

```bash
out/bnuyper
```

Or provide a file to practice typing its contents line by line:

```bash
out/bnuyper text/easy
```

You can even practice typing your own source code!

## Requirements
- Linux x86-64
- FASM
- Make
